# SoftSkill 🎮
### A Dialogue-Based Visual Novel for Developing Soft Skills

**SoftSkill** is an interactive dialogue-based visual novel designed to help players explore and practice essential soft skills through realistic workplace scenarios.

Instead of traditional lessons, players face professional challenges, make decisions, and experience the consequences of their choices.

---

## 📖 About the Game

The game puts the player in a simulated workplace environment where communication, teamwork, problem-solving, critical thinking, and professional decision-making matter.

Players must navigate different situations by choosing the most appropriate responses. Their decisions determine whether they successfully progress in their professional journey.

## ✨ Features

- **Interactive Dialogues:** Make decisions through branching dialogue choices.
- **Realistic Scenarios:** Experience situations inspired by common workplace challenges.
- **Decision-Based Progression:** Your choices directly affect the outcome of each level.
- **Multiple Characters:** Interact with different characters in professional situations.
- **Persian Language Support:** Designed for Persian-speaking players.
- **Cross-Platform Builds:** Available for Windows and Linux.

## 🚀 Getting Started

### Download and Play

1. Visit the [Releases](../../releases) section.
2. Download the appropriate version for your operating system.
3. Extract the downloaded archive.
4. Launch the game.

**Linux:** If the launcher is not executable, open a terminal in the extracted folder and run:

```bash
chmod +x softtSkill.sh
./softtSkill.sh
```

### Run from Source

1. Install the [Ren'Py SDK](https://www.renpy.org/latest.html).
2. Clone this repository:

```bash
git clone https://github.com/MohammadrezaTheFirst/SoftSkillGame.git
```

3. Open the project using the Ren'Py Launcher.
4. Launch the game.
